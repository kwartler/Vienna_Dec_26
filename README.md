## Before Day 1

1. Install R and RStudio: [posit.co/download/rstudio-desktop](https://posit.co/download/rstudio-desktop/)
2. Install Git: [git-scm.com/downloads](https://git-scm.com/downloads)
3. Clone this repository and open `Vienna_Dec_26.Rproj` in RStudio.
4. Install the packages listed below (list to come before class).
5. Complete the [pre-module assignment](winter_module_assignments/PreModuleAssignment/) for your track, due Friday, December 11, 9am CET via Moodle.
6. Optional: create an [OpenRouter](https://openrouter.ai) account and fund a small credit. A class key will also be provided. See [`keys.example.md`](keys.example.md) for where to store a key; never commit keys to a repository.
