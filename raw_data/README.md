# Raw data

Synthetic data behind the Bramble+ dashboard. All figures are fictional.

| File | Contents |
|------|----------|
| `bramble_monthly_kpis.csv` | Monthly subscribers, cancellations, churn, revenue, marketing and tenure |
| `bramble_churn_by_channel.csv` | Monthly churn by acquisition channel |
| `bramble_churn_by_plan.csv` | Monthly churn by plan |
| `bramble_churn_by_region.csv` | Monthly churn by region |
| `bramble_cohort_retention.csv` | Retention of each signup cohort by month since signup |
| `bramble_pricing_test.csv` | Results of the December 2025 pricing test |
| `bramble_exit_survey.csv` | Exit survey responses, July to October 2026 |
| `synthetic_data.py` | Script that generates the files above (`python synthetic_data.py`) |
