# Bramble+ executive decision challenge

A no-code group exercise: act as the leadership team of a fictional European streaming service and make a data driven decision about a churn spike.

| File | Purpose |
|------|---------|
| `A_scenario_brief.md` | The situation, the four options and what each group presents |
| `B_role_memo_CEO.md` to `E_role_memo_Head_of_Data.md` | Private role memos, one per group member |

The dashboard is a single page, built from the data in [`raw_data/`](../../../raw_data/) and published from [`docs/bramble_plus/`](../../../docs/bramble_plus/) on GitHub Pages. Its source is in `dashboard_src/`; rebuild it with `python lessons/day1/bramble_plus/dashboard_src/build_dashboard.py` from the repository root.

Bramble+ and everyone associated with it are fictional.
