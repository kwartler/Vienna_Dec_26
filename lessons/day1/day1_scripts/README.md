# Day 1 scripts

R scripts for Day 1, lettered in the order we use them in class.

| Script | Purpose |
|--------|---------|
| `B_bank_loans_decision_tree.R` | Decision trees on bank marketing data: an overfit full tree, then a caret tree tuned on cp |
| `C_bank_loans_random_forest.R` | Random forests on balanced bank marketing data: caret, randomForest with 3, 100 and 500 trees, OOB error, and ranger |
| `D_inn_hotels_challenge_STUDENT.R` | INN Hotels cancellations challenge: fill in the blanks to treat the data and compare logistic regression, decision tree and random forest models |
| `D_inn_hotels_challenge_KEY.R` | Completed challenge, shared for independent study |
| `G_consumer_credit_training.R` | LendingClub credit risk: treat the variables and fit a cross-validated logistic regression with caret; explore the cutoff |
| `H_consumer_credit_scoring.R` | Score new LendingClub notes and plot risk vs. reward to pick loans to fund |
| `E_inn_hotels_functions_STUDENT.R` | Writing R functions: refactor the INN Hotels challenge into reusable functions (fill in the blanks) |

Decks: `lessons/day1/B_Decision_Trees.pptx` and `C_RandomForests.pptx` for the B and C scripts; `lessons/day1/E_writing_r_functions.pptx` for the E scripts; `lessons/day1/G_ConsumerCredit.pptx` for the G and H scripts.
